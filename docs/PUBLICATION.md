# SceneCV 公开发布检查

日期：2026-11-16。这份记录说明这次发布检查了什么，不承诺发现了所有潜在问题。

## 发布范围

- 书桌房间：前端交互、烘焙好的模型和光照贴图、窗外夜景、场景清单，以及搭房间、烘焙光照、照片做旧的 Blender 脚本。
- 本地静态文件服务、第三方素材下载脚本、素材致谢生成脚本、公开发布检查脚本和测试。
- 没有账号、数据库或保存用户数据的后端。

## 内容和脱敏

- 姓名、介绍、电脑菜单、简历、作品、书单、照片和联系方式都是样例。作品是一盘样例节目（`assets/tapes/sample/`），四盘带子共用；软木板展示九张 CC0 东京照片，实验墙展示六张开放馆藏图版，出处随素材发布；书单保留了书的尺寸（房间是按尺寸烘焙的），书名、作者和划线都是占位文字。
- 唱机不带曲目：音乐有版权，`js/music-tracks.js` 是空的，里面写了怎么放自己的 mp3。
- 真实简历和联系方式、书的真实封面、个人照片、配乐和真实的录像带节目都不进仓库，只留在作者本地。
- 第三方素材的原始下载（`vendor-src/`）不进仓库，用 `node scripts/fetch_assets.mjs` 重新下载。
- 仓库从一次新的提交开始，不带以前的提交历史；提交署名用 GitHub noreply 邮箱。
- 代码用 MIT 许可证（`LICENSE`）；第三方素材和字体保留各自的许可证。

## 检查

```sh
npm test
npm run audit:public
```

- `audit:public` 检查已跟踪文件里的本机路径、私钥和常见令牌、带密码的链接、邮箱 / 电话 / 手机号、PNG 元数据，以及不该发布的文件夹。作者本地另有一份不进仓库的词表（`.private-terms`），用同一个脚本检查真名、学校、公司、项目名这类词有没有出现在公开文件里。
- 浏览器里检查了书桌房间的加载、各个物件的视角、电脑菜单、简历、录像带节目、书架、照片墙、致谢和纯文字版，README 的截图就是用这次发布的文件拍的。
- 没有做 Safari 和多设备的性能测试。

新增个人信息时，要同时检查 HTML、画在 canvas 上的文字、贴图、模型里打包的内容、文档和 Git 历史。
