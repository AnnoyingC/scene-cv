# SceneCV 公开发布检查

日期：2026-11-05。此记录说明本次发布的检查范围，不承诺发现所有潜在问题。

## 交付范围

- 书桌房间与塔楼书房，含前端交互、烘焙模型、灯光贴图、场景清单与 Blender 制作脚本。
- 原创现代桌面设备的可编辑 Blender 源文件、GLB、贴图和预览。
- 本地静态文件服务、素材下载工具、公开发布检查脚本与测试。
- 当前没有账号、数据库或保存用户数据的业务后端。

## 脱敏与历史

- 首页姓名、邮箱、社交账号、作品及书单使用占位示例。
- 清理两张设备预览图中的文本及 EXIF 元数据；保留原始像素数据。
- 原创 Blender 源文件改用相对纹理路径，包括打包纹理的内部路径，清理渲染输出路径；保留可编辑模型与打包贴图。
- 本机工具设置、个人学习记录、下载素材原件与临时打包目录保留在本地，不进入公开仓库。
- 旧的私有历史不复制到公开仓库；公开项目从脱敏后的完整快照开始。后续提交不应把旧历史合并回来。
- 仓库作者使用 GitHub noreply 邮箱；第三方作者的公开署名与素材来源保留。

## 文件服务

本地服务只绑定回环地址。限制可读取的目录及文件类型，拒绝隐藏文件、制作工具与越界符号链接；只接受 GET / HEAD。它用于开发预览，不包含生产环境的认证或存储功能。

## 可复现检查

```sh
npm test
npm run audit:public
```

另使用 Gitleaks v8.30.1 检查公开文件与提交历史，扫描结果不携带凭据原文。模型清单引用、实际素材署名、两个场景及纯文字回退还需结合浏览器进行检查。

本次验证：

- Node 24 环境下，文件服务的 16 项测试通过，包括隐藏文件、编码路径、越界符号链接和请求方法检查。
- 两个场景的模型与光照资源存在；源码通过 JavaScript / Python 语法检查。
- 浏览器验证：两个场景加载、物件进入介绍与作品、切换项目、返回、书单与联系方式路由、塔楼素材致谢，以及带异常 hash 的纯文字回退。
- 上述浏览器检查未捕获到控制台错误；场景截图保存在 `docs/images/`。
- 未重新烘焙整个房间，也未进行所有设备、所有角度的性能或视觉测试。

## 素材与后续变更

塔楼实际使用的 14 项由 `assets/tower/manifest.json` 的 `vendor` 字段列出，逐项对应 `assets/vendor/credits.json`，保留作者、原始链接、许可及修改说明。本次实际使用的外部素材来自 Poly Haven，标注 CC0，并核对了 [Poly Haven 官方许可说明](https://polyhaven.com/license)；尚未使用的候选素材不等于已经包含在场景模型中。

Sooah 参考仓库不随本次发布分发。SceneCV 暂未指定整个项目的代码许可证，第三方素材保持各自许可。

新增个人信息时，应同时检查 HTML、Canvas 屏幕、贴图、模型打包内容、文档和 Git 历史。新增保存或登录功能时，需要另行实现服务器校验、持久化与权限检查。
